# Topical Authority — pabrik.kacafilm.co.id

## Role and boundary

Repository evidence identifies pabrik.kacafilm.co.id as a legacy redirect shell to `kacafilm.co.id`, not as an independently evidenced manufacturer website. The only specific legacy route maps `kaca-film-pabrik-<kota>` to `kaca-film-gedung-<kota>`, so the defensible editorial scope is education for selecting, specifying, procuring, installing, testing, and maintaining building window film. The hub must teach readers how to verify manufacturer, converter, distributor, installer, OEM, and private-label claims; it must not assert factory ownership, production capability, product construction, optical performance, compatibility, certification, warranty, MOQ, price, or any other commercial fact without current documentary evidence.

## Context used

- No sitemap XML exists in the repository. Context therefore comes from the compact route/deployment evidence permitted by the lean workflow.
- The repository contains one `index.html`, a 25-byte README naming the hostname, `_redirects`, two small Go maintenance scripts, and two GitHub Actions workflows.
- `index.html` is an empty HTML5 boilerplate with no visible topical copy. It contributes no product or commercial-role evidence.
- `_redirects` sends the root to `https://kacafilm.co.id` with a 301 and maps `/2021/02/kaca-film-pabrik-:kota.html` to `https://kacafilm.co.id/kaca-film-gedung-:kota`.
- The redirect pattern supports building window film plus legacy location-page consolidation. It does not substantiate a manufacturer, factory, OEM, or private-label role.
- Mode lean is retained. Manufacturer/private-label, construction, optical, compatibility, testing, installation, certification, MOQ, logistics, warranty, and pricing claims are publication gates.

## Ignored template noise

- The dynamic city token in the legacy redirect is treated as location-template noise, not as a source of city-specific editorial topics.
- The boilerplate title “HTML 5 Boilerplate” and empty body are not used as semantic evidence.
- Generic Adsense/sitemap scripts and manual GitHub Actions workflows are implementation utilities, not product or quality evidence.
- The tiny README adds no context beyond the hostname and is not extrapolated into factory claims.

## Internal-link rule

Setiap artikel menaut ke hub topiknya, satu artikel pendamping dalam topik yang sama, dan satu atau dua topik tetangga yang mendukung langkah berikutnya. Artikel aplikasi dapat mengarah ke situs komersial kanonis setelah rute final dikonfirmasi; tidak ada artikel baru berbasis kota dan tidak ada tautan yang menyebut domain ini sebagai pabrik tanpa bukti. Pembahasan manufacturer/private label, konstruksi, VLT/UV/IR/TSER, optical metrics, glass compatibility, thermal stress, quality testing, cure, standards, certification, warranty, MOQ, logistics, dan price harus menahan angka atau klaim sampai dokumen aktual tersedia.
